Vini Stage

Instrumento VST3 Universal para Intel e Apple Silicon.

Este instalador coloca o plugin em /Library/Audio/Plug-Ins/VST3/, disponível para todos os usuários do Mac.

Feche o Ableton Live antes de continuar. A instalação pede a senha de administrador.

Intel: compilado para macOS 10.13 ou posterior. Apple Silicon: macOS 11 ou posterior. A execução no High Sierra ainda precisa ser validada no computador de destino.

Nenhuma biblioteca de timbres está incluída. Abra seus arquivos .npno pelo botão Select Sound.
