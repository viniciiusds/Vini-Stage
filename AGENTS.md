# Project workflow

- For implementation changes, the user authorizes compiling/installing, generating a versioned Universal PKG, updating documentation, committing/pushing directly to `main`, and publishing the PKG to GitHub Releases by default. Do not stop to ask again. Honor any explicit exception (e.g. analysis/image-only, do not compile, or wait to publish).
- Build and run relevant verification before committing. Never force-push or rewrite shared history without explicit authorization.
- Primary target: a universal macOS VST3, Intel x86_64 with deployment target 10.13 for a MacBook Pro 2011, plus arm64 for an M4 development Mac. Preserve both architectures.
- Keep two optional sounds A/B in a single Sounds LCD on the red right side. Shared grey volume area on the left, each fader with green setting LEDs on its right and a dB display. Select A/B becomes Clear A/B when a file is selected; clear removes/cancels only that slot and persists an empty path. Empty rows show only A: / B:. No ON/OFF buttons. Keep an 88-key A0–C8 mouse-playable keyboard at the bottom, highlighting incoming MIDI notes. Preserve legacy ON parameters and IDs for host automation/state compatibility. Selecting a new file re-enables its legacy ON parameter. Keep 1 dB steps (−60 to 0 dB plus −∞), both paths and controls, and restore legacy one-sound projects into A.
- Keep automatic installation after each successful VST3 build into `~/Library/Audio/Plug-Ins/VST3/Vini Stage.vst3`. Sign and verify the final bundle after generating the VST3 manifest, then copy and verify the installed bundle.
- As of 0.6.0, follow the user's superseding request to approach the observed Sharp piano engine: release gain follows a 50 ms recent pre-fader amplitude follower and normalized fixed take, not the old 2%-of-velocity rule. Use the highest recorded release layer, deferred under sustain. Do not trigger on unmatched/repeated note-off or panic.
- Preserve immutable PCM16 libraries shared on loader threads by path/size/mtime, single-flight decode, bounded 128 MiB idle retention, and cooperative cancellation on reads/between strokes. Never acquire cache locks, allocate, decode or free libraries in the audio callback.
- Do not commit piano libraries, extracted WAVs, credentials, dependency checkouts or build products. `.npno` test fixtures are supplied separately by the user.
- User confirmed operation on the 2011 High Sierra Mac with an Arturia controller. New audio changes still require audition there. Use validated file loop points for held/pedalled tails; neutral MIDI velocity is the new default; use separate calibrated selection and gain curves. Respect explicit boundary byte 0x74; only infer boundaries when all are absent. Container generation, not stream version, selects legacy metadata units. Audio equivalence remains unproven.

- Preserve the approved red/charcoal hardware layout, no manufacturer text in the header, no screws; lowercase vini stage logo beside the left of Levels near the keys, with its visible bottom aligned to the Levels panel bottom, small Select/Clear buttons and reduced top padding. README imagery must be rendered from the actual current editor, not the concept image.

- Display actual file-read/decode progress as Loading... X% in the corresponding A/B row of the shared Sounds LCD. Do not replace it with timer-driven progress. Align the Select/Clear buttons under the shared LCD and the LED column with the fader track; keep the dB LCD as wide as the fader/LED group and no visible Volume heading.
- Latest approved fader direction supersedes the earlier 20 px cap clearance: extend tracks upward with their lower ends fixed. Keep equal 20 px gaps from dB LCD bottom to LED top and from LED bottom to the A/B separator. The cap at its extremes has 6 px clearance from the LCD/separator. Keep LED columns aligned to the fader tracks.

- `package.sh` produces a legacy-compressed Universal PKG targeting macOS 10.13+, with independent VST3 and Standalone checkboxes. VST3 installs globally in `/Library/Audio/Plug-Ins/VST3/`, Standalone in `/Applications/Vini Stage.app`. Preserve independent receipts audio.vinizera.vinistage.vst3 and audio.vinizera.vinistage.standalone; shared documentation/licenses use audio.vinizera.vinistage.resources only when either is selected. Unselected bundles must not be installed, updated or removed; user-copy migration runs only for VST3. Keep its stable package identifier, non-relocatable/version-checked atomic bundle upgrade and safe per-user backup migration. Do not claim Developer ID signing, notarization or real High Sierra installation unless actually verified. Package tests must use isolated temporary roots and never run a real system installation without the user's explicit request.

- The user approved the keyboard/layout and authorized packaging/publication as 0.4.2. Preserve the approved layout in future builds.

- Main voice note-off fade is exponential as of 0.6.0, following the observed 500 ms reference scaled by per-sample release metadata, time to -80 dB. This supersedes the earlier approved 90 ms linear fade. Do not claim licensed Sharp audio A/B or perfect matching. Preserve its original binary/license; never commit proprietary binaries or decompiled code. The Vini has no separate master; document the Sharp default master -6 dB difference when comparing levels.

- String Res is explicitly deferred to docs/BACKLOG.md; do not implement without a new user request. Preserve the standalone icon: approved option 1: smaller white uppercase VS above a compact framed piano keyboard on the plugin red gradient, source in assets/ViniStage.svg and raster in assets/ViniStage.png, wired through JUCE ICON_BIG/ICON_SMALL.

- macOS icons must use assets/ViniStage.icns generated with assets/make-icon.py (legacy RGB/masks for small sizes, PNG for Retina). Replace JUCE-generated ICNS at configure time; its 16px PNG icp4 chunk produced visible corruption. Test decoded pixels, not just the presence of icon sizes.

- As of 0.6.5, pre-loop uses legacy bridge loop_decay (record 0x3a) scaled by playback step; in-loop uses legacy attack_decay (record 0x2e) scaled by source/host rate. Do not invert these phases again. Voice names preLoopDecay/postLoopDecay express their actual application. Fixed +10 dB is applied once after A+B sum; faders stay at max 0 dB. Keep the independent sine fixture phase/transposition/output-gain regression.

- Official 1.0.0 is the 0.6.6 layout/audio without Dyn Comp. 1.1.0 is a prerelease with the new approved Levels layout and global Dyn Comp OFF/1/2/3. As of prerelease 1.1.2, max boosts +4/+8/+12 dB at velocity 1, smoothstep fade to 0 at 127, no sample-selection changes. Capture gain per new voice; release follows the existing amplitude follower without double gain. Missing legacy dynComp state restores OFF. Preserve original parameter IDs and keep 1.0.0 as latest stable release until explicitly promoting a test version.
